<h2 id="heading-1"><span>项目介绍</span></h2>
<p><span>本项目用来为 Github 开发者可视化生成个性的</span><span><code>Github信息统计卡片</code></span><span>、</span><span><code>徽章</code></span><span>、</span><span><code>第三方项目统计信息</code></span><span>等。</span><span><strong><span>无需</span></strong></span><span>阅读项目复杂的配置文档，并有预览功能实现所见即所得的效果。项目集成</span><span><strong><span>多个</span></strong></span><span>Github 优秀的开源项目，并为用户做减法剔除了一些配置项。</span></p>

<h2 id="heading-3"><span>为什么使用</span></h2>
<p><span>首先大家需要明确一点，上述那些好看的徽标、卡片实际上都是图片。有些的数据是动态的，就是定期从github官方暴露出的api拿到用户相关参数。有想进一步了解的可以参考官方api文档</span><span><a href="https://docs.github.com/zh/rest?apiVersion=2022-11-28" target="_blank" rel="noopener noreferrer"><span>GitHub REST API 文档 - GitHub 文档</span></a></span></p>
<p><span>本项目其实就是根据图形化用户选择的表单配置项对参数进行了拼接，那有些人可能会说，那我用你的网站干啥，我自己去官方文档里面找不就好了，还能更加全面。</span></p>
<p><span>此言差矣，根据我多年瞎搞的经验来说，阅读官方文档是很痛苦的事情，大多数工具类项目还遵循91法则，并且项目提供的90%的配置项你的场景可能只有10%能用到。更何况这些开源项目几乎全是国外的，要么中文文档很少，要么直接没有，机翻还容易变味。</span></p>
<p><span>言归正传，说了这么多，我的项目优势是什么？</span></p>
<ol>
<li>
<p><span>集成了github主流的状态统计项目，包括但不限于65kstar的</span><span><a href="https://github.com/anuraghazra/github-readme-stats" target="_blank" rel="noopener noreferrer"><span>github-readme-stats</span></a></span><span>、23kstar的</span><span><a href="https://github.com/badges/shields" target="_blank" rel="noopener noreferrer"><span>shields</span></a></span></p>
</li>
<li>
<p><span>做减法。剔除了许多配置项，只保留作者认为的常用的一些配置项</span></p>
</li>
<li>
<p><span>图形化界面，所见即所得</span></p>
</li>
</ol>
